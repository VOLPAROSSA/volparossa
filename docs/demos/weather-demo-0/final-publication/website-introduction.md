## One shared core. Multiple applications.

VOLPAROSSA Weather is a development preview of an open participant network bringing shared resources within reach. The genuine Overmorrow Android app displays ECMWF IFS weather and NOAA GEFS-Aerosols PM2.5 forecasts retrieved through cooperating peers. Core runs externally in a Debian 13 test environment, not as a standalone Android Core or production mobile release. Forecasts are not observations or a complete AQI service. Labeled editorial cuts do not imply network performance; separate reports document cold peer delivery, cached reuse and background/resume. See the [full demo, evidence and limitations](https://github.com/VOLPAROSSA/volparossa/blob/a1f268d64dd3b2625c827f2ed77840c65d0a405c/docs/demos/weather-demo-0/README.md).
