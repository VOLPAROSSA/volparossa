# VOLPAROSSA Weather Demo 0

**Real forecasts. Shared through peers.**

This development preview shows the genuine Overmorrow Android app displaying ECMWF IFS weather forecasts and NOAA GEFS-Aerosols PM2.5 forecasts retrieved through VOLPAROSSA Core and cooperating peers. Core runs externally in a Debian 13 test environment, not as a standalone Android Core. Forecasts are model products, not live observations or a complete AQI service.

Labeled editorial cuts bring useful screens forward; app interactions remain at normal speed, and cuts do not imply network performance. Separate acceptance reports cover cold peer retrieval, cached reuse and background/resume; these are not all visible here. The original media-duration gate failed; separate scoped media admission later succeeded.

The recording does not establish physical-device compatibility or production readiness. See the [technical demo README](https://github.com/VOLPAROSSA/volparossa/blob/a1f268d64dd3b2625c827f2ed77840c65d0a405c/docs/demos/weather-demo-0/README.md) for the full demo and evidence. [NOTICES.md](https://github.com/VOLPAROSSA/volparossa/blob/a1f268d64dd3b2625c827f2ed77840c65d0a405c/docs/demos/weather-demo-0/NOTICES.md) preserves ECMWF, NOAA and Overmorrow attribution.
