## Weather Demo 0

**Everyday tools. Shared resources. More within reach.** This development preview shows the genuine Overmorrow Android app presenting ECMWF IFS weather and NOAA GEFS-Aerosols PM2.5 forecasts retrieved through VOLPAROSSA Core and cooperating peers. Core runs externally in a Debian 13 test environment, not as a standalone Android service. Forecasts are model products, not observations or a complete AQI service. The short presentation uses labeled editorial cuts; separately retained reports cover cold peer delivery, cached reuse and background/resume. It does not establish physical-device compatibility or production readiness. See the [full technical demo and evidence](https://github.com/VOLPAROSSA/volparossa/blob/a1f268d64dd3b2625c827f2ed77840c65d0a405c/docs/demos/weather-demo-0/README.md) and [attribution](https://github.com/VOLPAROSSA/volparossa/blob/a1f268d64dd3b2625c827f2ed77840c65d0a405c/docs/demos/weather-demo-0/NOTICES.md).
